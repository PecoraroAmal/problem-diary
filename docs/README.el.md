# Problem Diary

**Ένα μικρό σύστημα, ανεξάρτητο από την τεχνητή νοημοσύνη που χρησιμοποιείτε, για να κρατάτε ένα αναζητήσιμο ημερολόγιο με τα προβλήματα που έχετε λύσει, ώστε ο βοηθός AI σας να σταματήσει να ξεχνά.**

Γλώσσες: [όλες οι γλώσσες](../README.md)

## Η ιδέα

Αν μιλάτε κάθε μέρα με έναν βοηθό AI, λύνετε ξανά και ξανά τα ίδια είδη προβλημάτων, σε πολλές συσκευές και έργα. Ο βοηθός δεν θυμάται τις λεπτομέρειες και εσείς ξοδεύετε αρκετά αιτήματα για να ξαναχτίσετε το πλαίσιο.

Αυτό το έργο κρατά ένα ημερολόγιο σε απλό Markdown μέσα σε ένα αποθετήριο Git. Όταν λύνεται ένα πρόβλημα, ο βοηθός γράφει μια σύντομη καταχώριση: **ποιο ήταν το πρόβλημα, τα βήματα που πραγματικά δούλεψαν και το συμπέρασμα** (όχι όλη τη συνομιλία και όχι τις αποτυχημένες προσπάθειες). Την επόμενη φορά, ο βοηθός διαβάζει πρώτα το ημερολόγιο και βρίσκει την απάντηση με λιγότερα αιτήματα.

Είναι χρήσιμο αν έχετε πολλά έργα και συσκευές. Αν κάνετε μόνο γρήγορες, μεμονωμένες ερωτήσεις, δεν το χρειάζεστε.

## Πώς λειτουργεί

```
 συνομιλία με Claude ──"close and save"──▶ προσυμπληρωμένος σύνδεσμος ──▶ Claude Code στον ιστό ──▶ commit + push
        ▲                                                                                              │
        └──────── Claude Project (αποθετήριο GitHub ως γνώση, πατήστε Sync) ◀──────────────────────────┘
```

- **Εγγραφή:** το Claude Code (τερματικό ή ιστός) δημιουργεί την καταχώριση, εκτελεί `git pull`, commit και push.
- **Ανάγνωση:** το αποθετήριο προστίθεται σε ένα Claude Project ως γνώση. Μετά από κάθε νέα καταχώριση πατήστε το εικονίδιο Sync.
- **Χωρίς διακομιστή και χωρίς tokens στη συνομιλία.** Το ημερολόγιο είναι απλώς αρχεία στο δικό σας αποθετήριο, οπότε λειτουργεί με κάθε εργαλείο που διαβάζει Markdown.

## Απαιτήσεις

- Δικό σας αποθετήριο GitHub (και ιδιωτικό είναι εντάξει) που δημιουργήθηκε από αυτό το πρότυπο.
- Λογαριασμός Claude Pro, Max ή Team (απαραίτητος για το Claude Code στον ιστό).
- GitHub συνδεδεμένο στο [claude.ai/code](https://claude.ai/code), με την εφαρμογή Claude εξουσιοδοτημένη στο αποθετήριο του ημερολογίου.
- GitHub συνδεδεμένο με το claude.ai (η ενσωμάτωση GitHub), ώστε ένα Project να μπορεί να διαβάζει το αποθετήριο.
- Για μεγάλες καταχωρίσεις που δημιουργούνται από τη συνομιλία: ενεργοποιημένη εκτέλεση κώδικα και δημιουργία αρχείων στις ρυθμίσεις του Claude.

## Ρύθμιση

1. Δημιουργήστε ένα **ιδιωτικό** αποθετήριο από αυτό το πρότυπο και κλωνοποιήστε ή ανεβάστε αυτά τα αρχεία.
2. Συνδέστε το GitHub στο claude.ai/code και εξουσιοδοτήστε το αποθετήριο (δώστε πρόσβαση μόνο σε αυτό το αποθετήριο).
3. Δημιουργήστε ένα Claude **Project**. Στην ενότητα γνώσης πατήστε **+**, επιλέξτε **GitHub**, επιλέξτε το αποθετήριο και τα αρχεία που θα συμπεριληφθούν.
4. Εγκαταστήστε το skill από το `skill/problem-diary/` και στη γραμμή `REPO:` βάλτε το δικό σας `owner/όνομα-αποθετηρίου`.
5. Καταγράψτε τις συσκευές σας στο `diario/DEVICES.md`, με ένα επίσημο όνομα ανά συσκευή.

## Καθημερινή χρήση

Όταν λυθεί ένα πρόβλημα, πείτε στον βοηθό **"close and save"**. Ανάλογα με το μήκος χρησιμοποιείται μία από τρεις διαδρομές:

| Περίπτωση | Τι συμβαίνει |
|---|---|
| Σύντομη καταχώριση, από τη συνομιλία | Το skill ετοιμάζει έναν σύνδεσμο `claude.ai/code` με το prompt και το αποθετήριο ήδη συμπληρωμένα. Ανοίξτε τον και πατήστε Enter. |
| Μεγάλη καταχώριση, από τη συνομιλία | Το skill δημιουργεί το αρχείο `.md` με το σωστό όνομα και σας λέει τον ακριβή φάκελο. Ανεβάστε το από τον ιστότοπο του GitHub (*Add file > Upload files*). |
| Είστε ήδη στο Claude Code | Γράφει το αρχείο απευθείας: `git pull`, commit, push. Χωρίς όριο μήκους. |

Στη συνέχεια πατήστε **Sync** στο Claude Project, ώστε οι συνομιλίες να βλέπουν τη νέα καταχώριση.

## Δομή του αποθετηρίου

```
README.md                          ευρετήριο των μεταφρασμένων README
CLAUDE.md                          οδηγίες για τον πράκτορα κώδικα
docs/README.{lang}.md              README σε κάθε γλώσσα
diario/
  DEVICES.md                       επίσημα ονόματα συσκευών (ένα όνομα ανά συσκευή)
  _TEMPLATE.md                     πρότυπο καταχώρισης
  {device-slug}/
    YYYY-MM-DD-short-title.md      ένα αρχείο ανά λυμένο πρόβλημα
skill/problem-diary/               το skill "close and save"
  SKILL.md                         ροή εργασίας και κανόνες
  scripts/build_link.py            δημιουργεί τον προσυμπληρωμένο σύνδεσμο, ελέγχει μήκος και μυστικά
  assets/entry-template.md         πρότυπο που χρησιμοποιεί το skill (κρατήστε το συγχρονισμένο με το diario/_TEMPLATE.md)
```

Τα προβλήματα που δεν ανήκουν σε συγκεκριμένη συσκευή (ιστότοπος, κοινή υπηρεσία) μπαίνουν στο `diario/general/`.

## Μορφή καταχώρισης

Κάθε καταχώριση έχει τους ίδιους σταθερούς τίτλους, ώστε το grep και η αναζήτηση με AI να λειτουργούν αξιόπιστα: **Date, Device, Tags, Context, Problem, Solution, Conclusion**, συν τα προαιρετικά **Do not** και **Related**. Το περιεχόμενο το γράφετε στη δική σας γλώσσα. Δείτε το `diario/_TEMPLATE.md`.

## Όρια και απόρρητο

- Ο σύνδεσμος μεταφέρει την καταχώριση μέσα στο URL, οπότε τον χρησιμοποιούν μόνο οι σύντομες καταχωρίσεις. Οι μεγαλύτερες περνούν μέσω αρχείου.
- Το άνοιγμα του συνδέσμου και το πάτημα Enter παραμένουν χειροκίνητα: δεν είναι πλήρως αυτόματο και καμία καταχώριση δεν αποθηκεύεται χωρίς να τη δείτε.
- Κάθε αποθηκευμένη καταχώριση ξεκινά μια συνεδρία Claude Code στον ιστό, που μετράει στη χρήση της συνδρομής σας.
- Κρατήστε το αποθετήριο ιδιωτικό. Οι καταχωρίσεις περιγράφουν αναλυτικά τα συστήματά σας.
- **Μη βάζετε ποτέ κωδικούς, tokens ή κλειδιά σε μια καταχώριση.** Γράψτε αντί γι' αυτό πού φυλάσσονται.
- Ολόκληρο το αποθετήριο μετράει στη χωρητικότητα γνώσης του Project. Χωρούν εκατοντάδες σύντομες καταχωρίσεις.
- Ο συγχρονισμός GitHub στα Projects μπορεί περιστασιακά να καθυστερήσει ή να αποτύχει. Αν η συνομιλία δεν βλέπει μια νέα καταχώριση, πατήστε ξανά Sync και ελέγξτε.
